# ToDo — Secret Santa (бесплатный сервис без тарифов)

> Принцип проекта: **все возможности доступны всем бесплатно**. Нет страницы Premium, нет тарифов, нет оплаты, нет подписок, нет пробных периодов и даты окончания доступа.
> Источник идей для функций: описание расширенных возможностей santa-secret.ru и раздел FAQ (просмотрено 25.11.2026). Коммерческая модель исходного сайта не переносится.

## 0. Текущее состояние репозитория

- [x] Express 5 + Vue 3 + Vite 7 + Tailwind 4; `npm run dev` / `npm run build` работают.
- [x] Есть `/api/health`, `/api/message`, раздача `dist` в production, прокси `/api` в dev.
- [x] Нет базы данных, сессий, реальных игр, жеребьёвки и деплоя; чат не входит в первую очередь.
- [x] Есть дизайн-прототип: лендинг, темы, демо кабинета; полноценного роутинга и бэкенда пока нет.

## 0.1 Дизайн-прототип (готов)

- [x] Все 10 тем из исходного сайта добавлены в прототип; карточки показывают ночной и дневной вариант.
- [x] Демо кабинета организатора: прогресс, участники, ручное назначение пар и фильтр истории.

- [x] Подключены `.opencode/skills` и скилл `commit-and-todo` с правилами «коммит + ToDo»; `opencode.json` использует массив `skills`.
